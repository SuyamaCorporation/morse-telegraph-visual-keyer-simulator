# モールス電信キーヤーシミュレーター

スペースキーまたはクリックでモールス符号を入力し、Web Audio APIによるクリック音とビジュアルフィードバックで本格的な電信操作を体験できるシミュレーターです。

## 機能
- スペースキー長押しによるモールス符号入力（短音・長音の自動判別）
- Web Audio APIによるリアルな電信クリック音再生
- 入力されたモールス符号をリアルタイムにテキスト変換・表示
- 符号速度（WPM）の調整と練習モード

## 使い方
ブラウザで開き、スペースキーを短く押すと短音（・）、長く押すと長音（－）が入力されます。文字間の間隔が自動検出されてテキストに変換されます。
